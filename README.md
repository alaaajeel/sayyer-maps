# sayyer-maps

Offline map packs for the سَيّر (Sayyer) navigation app: one package per Iraqi governorate
(vector tiles zoom 9–14 + place-name index) and an Iraq overview (zoom 0–8).

Map data © OpenStreetMap contributors, available under the Open Database License (ODbL) — https://www.openstreetmap.org/copyright
Tiles built with planetiler using the OpenMapTiles schema — © OpenMapTiles.
